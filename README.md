# 🛒 Blinkit Grocery Sales Dashboard

📊 An interactive grocery sales analysis dashboard built using Power BI.

## 🎯 Project Overview
<img width="1346" height="751" alt="Screenshot 2026-09-10 000129" src="https://github.com/user-attachments/assets/0e3c790b-64b9-45aa-a4c0-35966fa51657" />

This project analyzes Blinkit grocery sales data to understand sales,
profit, orders, product categories, outlet performance, payment modes,
and delivery performance.

## 🎯 Objectives

- Analyze total sales and profit
- Track total orders and quantity
- Compare sales across product categories
- Analyze outlet-wise sales and profit
- Understand customer payment preferences
- Analyze delivery performance
- Provide interactive insights using Power BI slicers

## 📁 Dataset

The dataset contains 500 grocery sales records focused on Mumbai/Andheri
outlets.

Key columns include:
- Order ID
- Order Date
- Category
- Outlet Name
- Sales
- Profit
- Quantity
- Payment Mode
- Delivery Time
- Delivery Status
- Rating

## 🧹 Data Cleaning & Preparation

- Removed/handled missing values
- Checked data types
- Converted date and time fields
- Created delivery time in minutes
- Verified duplicate records
- Prepared data for Power BI analysis
